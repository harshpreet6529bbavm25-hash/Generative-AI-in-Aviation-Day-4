# 🧪 Practical Task 1 — Run a Vague Prompt

The lab tests the following prompt:

> Prepare a passenger announcement about the delay of Flight AV101.

The prompt specifically instructs the AI not to provide additional information such as:

- Reason for delay
- Expected departure time
- Airport
- Passenger instructions

The same prompt is run in both ChatGPT and Gemini.

---

# 🔍 What Students Observe

The outputs are compared based on:

| Observation | ChatGPT | Gemini |
|---|---|---|
| Announcement generated | Record output | Record output |
| Invented reason for delay? | Yes/No | Yes/No |
| Invented new departure time? | Yes/No | Yes/No |
| Asked for missing information? | Yes/No | Yes/No |
| Tone | Record | Record |
| Potentially misleading information | Record | Record |

### Key Learning

The prompt is intentionally vague.

The purpose is to identify whether the AI:

- Asks for clarification
- Makes assumptions
- Produces unsupported details

This demonstrates why precise prompts and human verification are important in aviation communication.

---

# ⚠️ Practical Task 2 — Identify Guesswork

Because the prompt does not provide actual operational information, specific details generated by an AI tool should be treated as assumptions.

The following information should not be invented:

| Detail | Provided in Prompt? | Safe to Use? |
|---|---|---|
| Airline name | No | No |
| Route | No | No |
| Departure time | No | No |
| Delay duration | No | No |
| Reason for delay | No | No |
| Gate number | No | No |
| Compensation | No | No |
| Food/hotel arrangements | No | No |
| Contact details | No | No |

### Key Principle

> If a detail is not provided or verified from an authoritative operational source, it must not be presented to passengers as a fact.

---

# ✈️ Aviation Verification

Information such as:

- Delay reason
- Revised departure time
- Gate
- Compensation
- Meals
- Accommodation

should be verified by authorised airline or airport personnel before communication.

# 🛡️ Practical Task 5 — Create a Safer Version

The safer prompt is:

> Prepare a professional airport announcement about the delay of Flight AV101. If any operational information is missing, insert [VERIFY WITH OFFICIAL SYSTEM] instead of guessing.

### Expected Safer Output

> Attention passengers travelling on Flight AV101.
>
> We regret to inform you that your flight has been delayed. [VERIFY WITH OFFICIAL SYSTEM]
>
> Please check the official airport display screens for the latest information regarding your flight.
>
> We apologize for the inconvenience and appreciate your patience and understanding.
>
> Thank you.

A professional-looking AI response can still contain incorrect information.
Vague prompts can encourage assumptions.
Specific prompts produce more controlled outputs.
AI should not invent missing aviation operational information.
Current operational details should be checked against official systems.
Human verification is essential before broadcasting important aviation announcements.
Prompt safeguards such as [VERIFY WITH OFFICIAL SYSTEM] can reduce hallucination risk.
ChatGPT and Gemini may handle missing information differently.
Image-generation prompts should clearly specify style, composition, colours and restrictions.
The AI tool should be selected according to the aviation business requirement.
🤖 ChatGPT vs Gemini

The lab shows that ChatGPT and Gemini may produce different responses when information is missing.

One tool may omit a detail while another may generate an assumption.

Therefore:

Different AI outputs should not automatically be treated as factual information.

👩‍💼 Human Verification

Before using an AI-generated passenger announcement, an aviation employee should verify:

Flight number
Route
Delay duration
Reason for delay
Revised departure time
Gate information
Passenger instructions

These details should be checked against the airline or airport's official operational systems.
